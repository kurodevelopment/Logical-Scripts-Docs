<AccordionGroup>
  <Accordion title="I get a missing export error">
    Ensure `logical-ui` starts before the calling resource and verify the export name and resource folder name exactly.
  </Accordion>
  <Accordion title="The UI is always visible">
    Check the client F8 console for a JavaScript error and confirm the NUI receives its initial hidden state.
  </Accordion>
  <Accordion title="The progress bar finishes but nothing happens">
    Check the returned boolean and the server event handler. A canceled progress action should not continue.
  </Accordion>
  <Accordion title="The interface is too large on some resolutions">
    Test at 1920x1080, 2560x1440, ultrawide, and lower resolutions. Avoid fixed pixel sizing for the main container.
  </Accordion>
</AccordionGroup>
