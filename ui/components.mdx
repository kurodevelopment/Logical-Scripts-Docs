| Component | Use case | Result |
| --- | --- | --- |
| Notification | Short player feedback | Non-blocking alert |
| Progress | Timed action | Progress bar with optional cancel |
| Input dialog | Collect structured values | Table of submitted values |
| Confirm dialog | Confirm a risky choice | Boolean response |
| Context menu | Present several actions | Selected action callback |

## Integration rule

Always check the documented return value before continuing an action. A player can cancel a progress bar or close an input dialog without submitting.
