---
title: "Configuration"
description: "Configure global styling and component defaults."
icon: "settings"
---

```lua config.lua
Config = {}

Config.Theme = {
    primary = '#E31B23',
    primaryLight = '#FF4D55',
    background = 'rgba(8, 8, 8, 0.94)',
    text = '#FFFFFF',
    muted = '#A1A1AA'
}

Config.Notification = {
    position = 'bottom-left',
    duration = 5000,
    sound = true
}

Config.Progress = {
    position = 'bottom',
    canCancel = true
}
```

<Note>
Keep global styling centralized so every script using Logical UI looks like part of the same product family.
</Note>
