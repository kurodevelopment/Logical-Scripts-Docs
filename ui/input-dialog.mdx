---
title: "Input Dialog"
description: "Collect validated text, number, select, and checkbox values."
icon: "text-cursor-input"
---

```lua
local result = exports['logical-ui']:Input({
    title = 'Create Invoice',
    fields = {
        {
            type = 'number',
            label = 'Amount',
            name = 'amount',
            required = true,
            min = 1,
            max = 100000
        },
        {
            type = 'text',
            label = 'Reason',
            name = 'reason',
            required = true,
            maxLength = 120
        }
    }
})

if not result then return end
print(result.amount, result.reason)
```

<Warning>
Client input validation improves usability, but server handlers must validate all submitted values again.
</Warning>
