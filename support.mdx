## Before opening a ticket

Confirm that you have:

- Read the installation and FAQ pages for the affected resource
- Restarted the resource after editing its configuration
- Tested without unrelated modified files where possible
- Copied the **complete** client or server console error

## Include these details

```text
Resource:
Resource version:
Framework and version:
Inventory:
Server artifact:
Steps to reproduce:
Full console error:
Changes made before the issue started:
```

<Warning>
Never post license keys, database passwords, webhooks, API tokens, or full `server.cfg` files in public support channels.
</Warning>
