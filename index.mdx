## Before installing

<Steps>
  <Step title="Confirm compatibility">
    Review the dependency and framework notes on the resource's installation page.
  </Step>
  <Step title="Download your purchase">
    Download the latest release from your purchase library and keep the original folder name.
  </Step>
  <Step title="Follow the resource guide">
    Install database files, inventory items, and dependencies before ensuring the resource.
  </Step>
</Steps>

<Tip>
When requesting support, include the resource version, framework, server artifact version, and the complete console error.
</Tip>
