```cfg server.cfg
add_ace group.admin logicalchat.staff allow
add_ace group.mod logicalchat.moderate allow
```

## Recommended permission split

| Permission | Access |
| --- | --- |
| `logicalchat.staff` | Staff chat channel |
| `logicalchat.moderate` | Clear or slow chat |
| `logicalchat.admin` | Configuration and broadcast tools |

Use your framework permission bridge only when its groups are reliably synchronized with server permissions.
