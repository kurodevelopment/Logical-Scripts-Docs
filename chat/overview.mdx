Logical Chat gives your community a polished chat interface with configurable commands, roleplay ranges, permission-based channels, and framework identity support.

## Features

- Modern responsive interface
- Local roleplay messages
- Job and staff channels
- Configurable command suggestions
- Anti-spam and length limits
- Framework name integration
