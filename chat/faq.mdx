<AccordionGroup>
  <Accordion title="I see two chat boxes">
    Another chat interface is still running. Review your resource start order and disable the conflicting replacement.
  </Accordion>
  <Accordion title="Character names are incorrect">
    Check the selected framework bridge and verify identity data exists for the active character.
  </Accordion>
  <Accordion title="Messages appear twice">
    A second resource may be listening to the same chat event. Search your resources for duplicate handlers or broadcast events.
  </Accordion>
  <Accordion title="Staff chat is visible to everyone">
    Stop the server and check the server-side permission handler immediately. Hiding messages in the UI is not sufficient.
  </Accordion>
</AccordionGroup>
